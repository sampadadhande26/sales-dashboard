# 📊 Sales Dashboard Using Power BI

### 1. Title
**Sales Performance Analysis Dashboard Using Power BI**

### 2. Purpose
The purpose of this project is to analyze sales data and create an interactive dashboard using Microsoft Power BI. It helps users understand sales performance, track revenue, identify top-performing products, and analyze business trends. The dashboard converts raw sales data into meaningful visual insights to support better business decisions.

### 3. Tech Stack
- **Microsoft Power BI** – Dashboard creation and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX (Data Analysis Expressions)** – Creating calculated measures and KPIs.
- **Microsoft Excel / CSV** – Data storage and input.
- **Data Visualization** – Charts, graphs, cards, and interactive filters.

### 4. Data Source
The dashboard uses a sales dataset containing information such as:
- Order ID
- Order Date
- Product Name
- Product Category
- Sales Amount
- Quantity Sold
- Customer Details
- Region or Location
- Profit (if available)

**Data Source:** Sample sales data in Excel or CSV format. A public sales dataset can also be used for analysis.

### 5. Features
- **Sales Overview:** Displays total sales, total orders, quantity sold, and profit (if available).
- **Sales Trend Analysis:** Tracks sales performance over time using charts.
- **Product Analysis:** Identifies top-selling products and categories.
- **Regional Analysis:** Compares sales performance across different regions.
- **Interactive Filters:** Filters data by date, product category, and region.
- **KPI Cards:** Highlights important business performance indicators.
- **Dynamic Visualizations:** Presents sales insights through interactive charts and graphs.

### 6. Key Highlights
- Converts raw sales data into an interactive dashboard.
- Provides a clear overview of business performance.
- Helps identify sales trends and top-performing products.
- Supports data-driven decision-making.
- Demonstrates practical skills in Power BI, Power Query, and DAX.
- Presents business insights in an easy-to-understand visual format.

### 7. Project Outcome
This project demonstrates how Power BI can be used to analyze sales data, visualize important business metrics, and identify patterns that support better sales and business decisions.
